# Dota 2 Match Advisor

Магистерский проект: по replay-файлам матчей Dota 2 строит модель, которая на каждом отрезке матча подсказывает, какую стратегию сейчас выгоднее выбрать (фарм, пуш, ганг, тимфайт и т.д.), и оценивает, насколько эта рекомендация уверенная.

## Зачем

Обычно разбор реплея — это ручная работа: пересматривать запись и самому решать, что команда делала в каждый момент. Здесь вместо этого разметка автоматизируется моделью, обученной на вручную размеченных матчах, а поверх неё считается ожидаемое влияние каждой возможной стратегии на итоговую победу — то есть не просто классификация "что происходит", а рекомендация "что делать дальше".

## Как это устроено

```
.dem replay-файл
        │  сторонний open-source инструмент OpenDota parser (Java, не входит в этот репозиторий)
        ▼
построчный JSON лог событий матча
        │  slot_hero.py            — какой герой на каком слоте
        │  slots_by_match.py       — разбивка по матчам + роль героя (core/mid/support...)
        ▼
data/by_match/*.csv
        │  feature_extractor.py    — бьёт матч на 30-секундные интервалы, считает позиции,
        │                            нетворс, киллы/смерти, "плотность" героев, разницу
        │                            нетворса команд, вардов, тауэров/рошанов
        ▼
data/features_hero/*.csv  (с пустой колонкой label под ручную разметку стратегии)
        │  rename_col.py           — переименовывает slotX_* в роль (core_r, mid_d...),
        │                            чтобы фичи были сравнимы между разными матчами
        │  mod_features/win_lose_colums.py — вручную проставляет, кто победил
        ▼
data/winrate/*.csv  (фичи + ручная разметка стратегии + результат матча)
        │  other_model.py / train_model.py — классификация стратегии по фичам
        │                            (SMOTE / RandomOverSampler под дисбаланс классов,
        │                            подбор гиперпараметров) — автоматизирует ручную разметку
        │  state_generate.py       — обучает регрессор Q(состояние, стратегия) → вероятность победы
        ▼
models/ (model.joblib, win_imputer.joblib, win_regressor.joblib)
        │  recommedation.py        — на новом матче для каждого тайминга считает Q
        │                            для всех стратегий, рекомендует лучшую, предупреждает
        │                            при низкой уверенности, строит график
        ▼
рекомендации по ходу матча + recommendations.png
```

## Как запустить

```bash
pip install -r requirements.txt
python slot_hero.py
python slots_by_match.py
python feature_extractor.py
python mod_features/win_lose_colums.py   # запускать из корня проекта, спросит id матчей-побед
python state_generate.py
python recommedation.py
```

Часть шагов интерактивна (разметка победителя, разметка стратегии по времени) — это ручной труд, который автоматизируют модели на следующих шагах пайплайна.

## Известные ограничения

- **Парсер отрабатывает не идеально** — в части реплеев были замечены ошибки при парсинге, что выявилось именно на этапе ручной разметки. Автоматической валидации корректности разбора реплея в пайплайне нет.
- Парсинг реплеев через Docker-образ OpenDota parser на слабом железе был нестабилен (падения, конфликты портов при попытке параллельного парсинга нескольких реплеев) — из-за этого датасет собирался небольшими партиями.
- Шаг `rename_col.py` (приведение фич к ролям вместо слотов) не для всех матчей был доведён до конца — часть данных в `data/features_hero` осталась в исходной slot-нумерации.
- Датасет собран вручную и небольшой (единицы матчей) — модель демонстрирует подход, а не production-качество.

## Стек

Python, pandas, numpy, scikit-learn, imbalanced-learn, joblib, matplotlib. Разбор `.dem`-реплеев — сторонний open-source инструмент OpenDota parser (Java).

## Статус проекта

Учебный проект (магистратура), пайплайн end-to-end рабочий на собранном датасете.
